## 0. 一页总览（核心规则）

1. 一件装备有**四个独立维度**：**品阶**（凡/良/上/精/极/灵/玄/神/觉醒，按等级段决定，决定用哪一档强化材料）× **档次**（破碎/普通/优秀/完美/光芒，按打造材料等级决定，影响白字基础值）× **颜色**（白/绿/蓝/紫/橙＝0/2/3/4/5 条蓝字附加属性）× **孔**（当前孔数/最大孔数，孔有四种颜色）。
2. 浮窗属性分层：白字**基础属性** →（升星、铭刻放大）；蓝字**增强属性**（颜色决定条数，可改造重随）；绿字**绑定属性**（1 条，打造时随机）；**通灵属性**（最多 5 条，靠“通灵”道具附上）；**附魔**（防具物防/法防）；**宝石**（逐孔镶嵌）。
3. **打造**：选 类型→等级段→装备→档次，按配方投材料，可加倍（最高 5~6 倍＝“满倍”）；“模拟打造”先看白~橙概率。满倍时橙色 100%、最大孔数固定 10；当前孔数（0~10）、孔色、绑定属性仍随机。
4. **升星** 0→13：每次消耗“同品阶升级宝石”×基数(1~5)+银；失败宝石没了且**掉星**（星越高掉越多），装备不碎。
5. **铭刻** 0→9：每次 1 颗同品阶生命石；武器每级 +3% 基础攻击，防具每级 +2% 基础防御 +0.5% 生命上限；**7 级以上失败直接掉回 1 级**，放“温玉”可免掉级。
6. **孔与宝石**：打孔器（同品阶、对应第 N 孔）把当前孔数加到最大孔数；孔色 4 种：粉红（五维）、淡紫（攻击）、天蓝（防御）、鹅黄（闪避/命中/爆击类）；宝石只能进同色孔；同色孔最多 6 个；洗孔符重随未镶孔的颜色，粉/紫概率低。
7. **宝石** 1~7 级（新版不分品阶）：≥3 块同级同种＋合成符合成升 1 级，基数 3~5，5 块＝100%，失败吃掉基数数量的宝石；可雕琢（普通/无暇/完美）；5 级以上可做双色宝石。摘除：低级符降 2 级（1~2 级直接没），高级符（同级）无损。
8. 其他改造：**附魔**（60 级以上 5 件防具，物防/法防二选一，1~6 级，耗元神）、**通灵**、**开光**（鉴定类装备重随品质/颜色/孔，会清空星和宝石）、**属性改造**（重随蓝字，可锁定）、**套装改造**（同系列 8 件触发套装属性和换装）、**觉醒**（140+ 神套/神器，12 孔全开，带等级成长）、**分解**（绿色以上出精华）、**修理**（普通修理降耐久上限，高级修理不降）。

## 2. 品质体系（三个维度别混）

### 2.1 档次（打造材料决定，影响白字基础值）
破碎 < 普通 < 优秀 < 完美 < 光芒【已证实｜4399FAQ“档次越高，基础属性也越高”】。
- 档次由投入的主材料等级决定：大致 五等→破碎，三等→优秀，二等→完美，一等→光芒【已证实｜onijiang、4399全攻略“破碎用五等材料，光芒用一等材料”】；普通≈四等【推测】。
- 各档次基础值倍率【推测，供调参】：破碎 0.6 / 普通 1.0 / 优秀 1.15 / 完美 1.3 / 光芒 1.5。
- 光芒套另有更好的通灵：光芒套“每件 90+ 敏耐的通灵”【已证实｜D-惊舟】。

## 4. 打造（装备制造）

### 4.1 UI 流程【已证实｜官指、4399FAQ、uhelp】
1. 按 **K** 打开「打造」面板 → 「装备制造/装备打造」页签。
2. 依次选：**类型**（职业武器/头饰/衣服/…/戒指/饰品）→ **等级段**（1–19、20–39 …、115、120、125…）→ **具体装备** → **档次**（破碎…光芒）。
3. 面板列出配方：主材料 + 数量，每项后面有输入框可**加量**；可放辅助材料。
4. 点 **「模拟打造」** → 显示 白/绿/蓝/紫/橙 五档概率。
5. 点 **「打造」** → 动画 → 装备进背包。

### 4.3 倍数与品质概率
- **倍数**：主（稀有）材料投入基础量的 N 倍。优秀 4 倍三等≈22% 橙；完美 5 倍二等≈45% 橙；光芒 6 倍一等＝100% 橙【已证实｜onijiang】。D-惊舟写“稀有材料投入 5 倍就是满倍”【冲突，见 Q3】。
- **满倍打造技巧**：先把上古拉到 999，再逐个加玄兵，模拟到橙色 100% 为止；之后可回减上古而不影响 100%【已证实｜D-曦月】→ 说明概率公式里**稀有材料（玄兵）权重远高于上古**，上古有上限 999。
- **满倍只保证**：橙色 + 最大孔数 10；**不保证**当前孔数、孔色、绑定属性【已证实｜D-惊舟】。“一般 8 元的太冥在 6 孔左右”【已证实】。
- 概率公式【推测，可实现】：
  ```
  score = Σ(材料数量 × 材料等级权重 × 材料种类权重) / 配方基础score   // 约等于“倍数”
  P(橙) = clamp( (score-1)/(满倍-1) , 0, 1 ) ^ k   // k 让中间档贴近 22%/45%
  其余概率按 白:绿:蓝:紫 = 1:3:4:4 分配剩余部分
  ```
- **孔**：最大孔数＝满倍时 10，未满倍时 6–10 随机【推测】；当前孔数 0~最大孔数，分布偏中（均值≈6）【推测，贴合“8 元太冥 6 孔左右”】。孔色按第 6.2 节权重。

### 4.4 原料合成（材料升等）
- 五等→四等→…→一等，**5 合 1 成功率 100%**【已证实｜D-惊舟、4399FAQ】；附魔石、武装原料 5 合也不是 100%【已证实】。
- 可设合成基数 2~5，**二合成功率 40%**【已证实｜D-惊舟】；“25 个玄兵三等合成 1 个一等”＝5×5【已证实｜D-曦月】。
- 失败：投入材料全部消耗【推测】。“垫刀”玄学不做进规则（用普通独立随机）。

## 8. 附魔【已证实｜官指·附魔、D-惊舟、D-曦月】

- 套装改造后不能再属性改造【已证实｜官指·套装改造】。

### 10.6 分解【已证实｜官指·装备分解】
- 只有绿色以上能分解（白装不行）；颜色越高、星越多、宝石越多，出高级材料的概率和数量越高；分解前界面会显示可能产出。
- 产出精华：凡品→刀剑精华，良品→战意精华，上品→神秘精华，精品→真气精华/无色精华，灵品→灵淬精华；品质太好可能出下一级精华。另出宠物修为药材料（尘土/碎片/精华）。
- 精华用于打造饰品、戒指。

### 10.7 耐久与修理【已证实｜官指·修理、D-惊舟、截图】
- 字段 当前/上限（650/650、527/650）。战斗消耗耐久；低于上限 10% 提示，归零后**该装备属性失效**。
- **普通修理**（城镇武器商/杂货商，银票）：修满，但**耐久上限下降**。
- **高级修理**（物品栏直接点，银子；白银 VIP“白银精修”）：修满，**上限不降**。
- 每场战斗掉耐久【推测】：每件 -1（受击防具 -1~2）。普通修理每次上限 -5%【推测】。

### 10.8 绑定、交易、出售【已证实｜D-惊舟、截图、4399FAQ】
- 装备状态：已绑定 / 未绑定。绑定后才显示蓝字（未绑定显示“？？？”）。

- 出售单价（卖 NPC），截图为 1 文银票。

### 10.9 货币（与打造相关）【已证实｜D-惊舟】
金（可交易）/ 金票（绑定）/ 银（可交易）/ 银票（绑定）。升星、铭刻、合成、洗孔消耗银或银票；高品阶（灵品以上）升级宝石和生命石**不能用银票直接买**，靠葫芦/副本/徽章/兑换券【已证实｜D-曦月】。

## 12. UI 流程（打造面板 K 的页签结构）
【已证实｜官指各页】一个「打造」窗口，左侧页签：
1. **装备制造**：类型/等级/装备/档次下拉 → 材料格 + 加量 → [模拟打造] [打造]
2. **原料合成**：放材料 → 基数 2~5 → [合成] [自动合成]
3. **装备强化**：子页 升星 / 铭刻。装备格 + 材料格 +（铭刻：温玉格）+ 基数 + 目标等级 → [升级] [自动升级]，按钮上方显示成功率和银耗
4. **装备打孔**：装备格 → 打孔器格亮起 → [打孔]
5. **装备洗孔**：装备格 → 每个空孔下方一个洗孔符格 → [确定]
6. **宝石镶嵌**：装备格 → 孔位 → 拖宝石进对应颜色孔
7. **宝石摘除**：装备格（有宝石的孔显示为空）→ 放摘除符 → 逐个摘
8. **宝石制造**：子页 宝石升级 / 宝石雕琢 / 双色合成
9. **装备附魔**：装备 + 附魔石 + 辅助（归元灵玉）+ 元神倍数 → 显示银票、成功率、元神 → [附魔]
10. **装备改造**：子页 属性改造（锁定勾选）/ 开光 / 装备通灵 / 套装改造 / 觉醒
11. **装备分解**：放装备 → 显示可能产出 → [分解]
NPC 流程：无尚升级（职业 NPC/段冶子/贝赫宁水/伽蓝真一）、无限宝石（修行客·超级升星）、三配件兑换（天尊）、重铸、普通修理（武器商/杂货商）。
背包：右键/拖拽穿戴；「鉴定」按钮；「高级修理」按钮。
