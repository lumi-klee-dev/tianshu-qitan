## 4. 元神系统（人物属性面板【元神】页签）

> 先澄清：**“元神”在原作里既是一种资源（元神值），也是一个面板**。面板下有 3 块：**天资、地灵、经脉**。元神值还被附魔、灵修、精灵培养等消耗。【已证实｜官指·元神概述 26259、官指·天资地灵 26260、官指·属性技能 26261、官指·经脉 51660】

### 4.1 元神值（资源）
- 60 级以上才能获得。按角色等级有**上限**，超出部分作废（数值未公开，缺口截图 #1 → 默认 `上限 = 等级 × 20 万` ⚙）。
- 来源【官指 + D-惊舟】：

| 来源 | 数量（公开的） |
|---|---|
| 元神系统任务（60 级起） | 未公开 |
| 元神丹（祝福宝箱开出） | 未公开 |
| 护送粮草、海底古先长老日常、湖底日常、通天日常（淡淡的元气兑换） | 每个日常几百 |
| 坠龙城守卫、保卫灵昌、跑环（每日 4 轮×20 环，天灵酿 +10 环） | 未公开；可配元神药加成 |
| 活力挂机 | 每点活力 1100~2500 元神（看修为） |
| 高级除妖（高除）/ 特级除妖（特除） | 每天 40 万 / 60 万 |
| 活跃度 50 / 100 | 3000 / 5000 |
| 迷魂谷残卷 | 可换元神 |

- 用途：升天资、升地灵（+银票）；装备附魔（倍数越高成功率越高）；灵修；精灵/萝莉培养（<139 级：普通 3.05 万、金票 2.60 万；≥139 级：4.50 万 / 3.90 万）【D-惊舟】。

### 4.2 天资（职业属性技能）
- 4 种属性，**每个职业固定一种**：侠客＝**玄**、刺客＝**毒**、术士＝**火**、修真＝**冰**。
- 消耗**元神值 + 银票**提升天资等级（每级耗费未公开，缺口截图 #1 → 默认 `元神 = 2000×级²`、`银票 = 2×级 两` ⚙）。天资等级达到要求后，技能图标点亮，再用**天资技能书**学（1 级书来自元神任务；2 级书可从“宠物大作战”10~15 环获得；古墓徽章也能换天资书）。
- 天资技能是**独立技能系统**：和心法、普通技能等级无关；在技能面板的「天资」页签使用。
- 职业克制（对谁伤害更高）：玄→刺客、毒→修真、火→侠客、冰→术士。

| 职业 | 天资技能 | 类型 | 效果 |
|---|---|---|---|
| 侠客 | 玄风刃 | 单体攻击 | 玄属性伤害；对刺客更高；附加“衰竭”（降物攻、法攻，回合随等级） |
| 侠客 | 玄霸击 | 单体 | 1 回合霸体嘲讽：目标只能打你，打你时被反弹玄属性伤害 |
| 侠客 | 千军破 | 群体攻击 | 玄属性伤害；**自身生命 ≥30% 上限才能用** |
| 刺客 | 毒龙手 | 单体攻击 | 毒属性伤害；对修真更高；附加中毒 |
| 刺客 | 迷雾绝杀 | 单体攻击 | 隐身 1 回合（被攻击优先级最低），下回合造成大量毒伤 |
| 刺客 | 绝佳时刻 | 群体攻击 | 目标未中毒：单体毒伤；已中毒：十字范围毒伤并清掉中毒 |
| 术士 | 玄天心火 | 单体攻击 | 火属性伤害；对侠客更高；附加灼烧 |
| 术士 | 火神天将 | 群体 | 火属性伤害，十字范围附加灼烧 |
| 术士 | 疾风烈焰 | 单体攻击 | 火属性伤害，目标速度越快越痛；**自身法力 ≥50% 才能用** |
| 修真 | 如履薄冰 | 单体攻击 | 冰属性伤害；对术士更高；附加迟缓（降速） |
| 修真 | 神武冰旋 | 十字范围 | 冰属性伤害；概率挂“冰系易伤”（最多 5 层） |
| 修真 | 寒冰复生 | 辅助 | 给己方挂 buff，期间死亡自动复活；最多 4 回合 |

- 天资技能 1~8 级的需求（BWIKI 表，没写单位，**推测是人物等级**）：第一天资 114/124/132/140/148/156/164/172；第二、三天资 150/156/162/168/174/180/186/192；二转天资 1 级 114。
- 天资等级与技能等级的对应没公开 → 默认 `学第 L 级需天资等级 ≥ 5L` ⚙。天资技能伤害公式没公开 → 默认 `(1.0+0.08L)×(主攻+50+40L)×克制系数(1.2)` ⚙。
- 实战：二转 125 点完武功前，人物输出主要靠**第一天资**；转生前建议天资技能 ≥3 级、天资等级 ≥30（另一份写 ≥40）【D-惊舟、D-曦月】。

### 4.3 地灵（属性抗性）
- 同样分玄、毒、火、冰 4 项，**每项减免对应属性天资技能的伤害**；消耗元神 + 银票升级，4 项都能升（不限职业）。
- 每级减伤没公开（缺口截图 #19）→ 默认 `减伤% = 1.5 × 地灵等级`，上限 60% ⚙。

### 4.4 经脉
- 位置：人物属性 → 元神 →「经脉」。口号“八脉一通，谁敢不从”→ **8 条经脉**；每条 **6 个穴位**，每个穴位 **10 层**。
- 升级消耗**技能经验 + 人物经验**；每个穴位到第 10 层“激活”时额外消耗 **大还丹**（金币商城）。
- 效果：每层加人物属性；激活穴位后获得**技能加成**（例：督脉 50 层后穿心蚀骨强化，见 §2.3；经脉对圣灵附体有 50% 加成，系数从 0.0886×法攻 变 0.133×法攻【D-惊舟】）。
- 经脉名、每层属性、每个穴位的技能加成都没公开 → 见缺口截图 #5。默认 8 脉名用奇经八脉（任、督、冲、带、阴维、阳维、阴跷、阳跷）⚙；每脉对应 1 系心法，6 个穴位中第 5 穴（50 层）给该系转生技能强化、第 6 穴（60 层）给 11 级技能额外效果 ⚙。
