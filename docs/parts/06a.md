## 6. 宠物系统（宠物面板 P）

### 6.1 获取与捕捉
**获取途径**【已证实｜官指·宠物系统常见问题 6652、宠物大全】：野外捕捉（大多数）、任务奖励（如 30 级灵昌城黄一凡送包子仙）、宝箱/活动、副本徽章兑换、消费徽章兑换、交易行购买。

**捕捉规则**：
- 战斗中对野怪下“捕捉”指令。可捕捉的怪和宠物大全里“出现地”一致；妖怪系里很多怪“不可捕捉”。【已证实｜4399宠物大全】
- 捕捉道具【已证实｜官指·道具介绍 6579；搜索摘要转述 t.imop】：

| 道具 | 作用 |
|---|---|
| 猎户之眼 | 对怪物使用，捕获几率 +20% |
| 猎户之心 | 对怪物使用，捕获几率 +40% |
| 锁魂卡（普通卡/头领卡/宝宝卡） | 灵昌城钟无烟处买，约 5 两 / 10 两 / 100 两银；普通卡 70 级可用；抓“头领”类宠物（巨蝎、青牛头领、大乌鸦头领等，**可直接抓到变异**）【D-进化宠】 |
| 乾坤袋（约 666 两银） | 咆哮谷冰雪巨人（成功率约 1/5）、埋骨之地石人（约 1/15）【D-进化宠】 |
| 混天绫 / 幌金绳 / 缚妖索 / 彩虹缚 | 指定宠物专用：红翼蝶女（密霞谷）/ 蚌精（遗忘废墟）/ 月海水妖（迷雾海）/ 九尾（必须彩虹缚） |
| 香料棒、甘叶草、东坡肉、彩虹缚 | 宠物岛一层货郎（10,59）限量出售，每 6 小时刷 5 个，100 两银票【官指·宠物岛】 |
| 青瓷炼妖壶 / 老君壶 / 混元袋 | 时雨山等地图“壶中几率获得”野猪、灵猿、猛虎、云鹤、五色鹿等 |

- **宠物岛**【已证实｜官指·宠物岛 24776】：40 级以上从碧波水域（3,10）进入；一层 40 级、二层 45、三层 50、圣兽岭 60。周五~周日 11:30–13:30、17:30–21:30 是活动时段：每条线每小时在圣兽岭刷 1 只**稀有宠物**（整点前后随机几分钟），只允许 1 个玩家点击，读条 10 秒进战斗，15 分钟没人打就消失；等待中被别的玩家袭击/切磋会被打断（袭击不加 PK 值）。部分稀有宠需要专用道具。
- **捕捉时随机生成**：资质（在种族区间内）、成长率档、是否变异（很低概率）、天赋技能。玩家资料显示“实际捕捉上限”比资质上限低 3~8%（例：巨蝎强壮上限 8150，实际最多抓到 8130；冰雪暴熊 8700 / 8200）【D-进化宠】。
- **基础捕捉率公式没公开** → 默认 ⚙：`成功率 = clamp(基础率 × (1.5 − 当前HP/最大HP) × 等级修正 + 道具加成, 1%, 95%)`；基础率：普通怪 40%、头领 15%、稀有/神兽 5%；等级修正 = 人物等级 ≥ 怪等级 时 1.0，否则每低 1 级 −5%；变异概率 1%（头领 5%）⚙。
- 刚抓到的宠物**未绑定**：首次参战提示绑定，绑定后才能参战；未绑定的宠物可交易。
- **宠物栏**：初始 2 格；20 级（灵仙岛李香香）、40 级（灵昌城钟无烟）、70 级（坠龙城越灵汐）任务各送 1 格；商城「驭兽密录」再加；**最多 10 格**。【已证实｜官指 6652、宠物属性综合介绍】

### 6.2 宠物属性面板【已证实｜官指·宠物详情 6596、宠物属性综合介绍 t.imop 200.htm、宠物系统常见问题 6652】

| 字段 | 规则 |
|---|---|
| 类型/系别 | 神兽系、野兽系、人形系、妖怪系、精灵系（宠物大全分类）；老版本另写“野兽、仙兽、神兽、妖精、人型五种，互相相克” —— 相克表没公开 ⚙ |
| 等级 / 成长上限 | 成长上限＝能升到的最高等级；**洗髓丹**每颗 +1（按当前上限用不同品质）；飞升后提到 180 |
| 携带等级 | 人物等级 < 携带等级时不能参战；**悟性 10 以后每 +2 悟性，携带等级 −1**（这样宠物等级可以超过人物） |
| 性别 | 雄 / 雌 / 无（生育系统官方说过“未来开放”，没上线） |
| 绑定 | 首次参战绑定；绑定后才能参战、领悟、契约 |
| 资质（5 项） | 耐力、强壮、敏捷、智力、信仰资质：决定升级时该项一级属性涨多少；每个种族有区间（见 §6.17 名单） |
| 成长率（5 档） | 普通、优秀、杰出、卓越、完美；“普通 100%，完美 400%”（官方原话）；非变异的完美实际在 340%~400% 之间随机【官指·幻化】；幻化后变“超凡”400%~460% |
| 变异 | 捕捉时极低概率；**资质约 +10%**，资质上限也 ×1.1（例：巨蝎强壮上限 8150 → 变异 8965）【D-进化宠】；在“查看详情”里看 |
| 悟性 | 提高基础属性（按百分比）、降低学书遗忘率、提高领悟成功率、降低幻化失败率、降低携带等级 |
| 修为 | 初始 0/20，每升 1 级上限 +20；使用天赋/主动技能时概率获得（高等级宠物用低等级技能不涨）；书学技能需要修为；影响高级技能威力 |
| 寿命 | 0 时不能参战；升级时补满并提高上限；延寿露 +200；“长寿”天赋提高上限；部分大招消耗寿命（水魔爆、风魔爆、龙息·乱等） |
| 忠诚 | 刚抓到时不满（和种族有关）；随战斗次数慢慢下降；宠物食品 +30、城镇治疗 NPC 恢复；过低时战斗中**不听指挥或拒绝出战** |
| 亲密度 | 一起出战、给它治疗会涨（具体作用官方写“未开放”） |
| 抗性 | 影响受到属性伤害的大小和中异常状态的概率 |
| 仙丹栏 | 放资质丹（宠物仙丹），升级时消耗；“自动放入”按钮 |
| 技能 / 技能书栏 | 见 §6.5 |

**悟性提升**【已证实｜官指 6652、道具介绍；D-曦月】：
- 低级悟性丹最高到 7（道具页写 8【冲突，取 7】）、中级到 12、高级到 20；悟性越高越难，失败**不掉级**（商城丹）。官方老设计里 NPC 吞宠提悟性失败会 −1，没上线。
- 实战：19 → 20 要“举世无双悟性丹”或大量高级丹；20 → 25 用“特级悟性丹”（觉醒后悟性上限才到 25）。成品宠常见 19/23/24/25。
- 每颗成功率没公开 → 默认 ⚙：`成功率 = 100% − 4.5%×当前悟性`（低级/中级/高级丹分别只能用到 7/12/20），19→20 举世无双 100%，20→25 特级 `40% − 5%×(悟性−20)`。

**修为节点**【玩家实测｜D-曦月】：6.4 万好开第 2 排内丹；12 万不被碧琅水榭的怪魅惑；13.8 万好开第 3 排内丹；**16 万＝飞升要求，也是上限**。提升用药品制作的「宝丹」「晶露」（舍身宝丹、培元宝丹、如意宝丹、灵犀宝丹等）和灵悟石。

### 6.3 成长与加点
- 每升 1 级：5 项一级属性按“资质 × 成长率”自动成长，**另给 1 点自由潜力**（官方老资料）；**每进化 1 级再给 5 点**（§6.8）。
- 官方 FAQ 举例：同资质下，普通成长率某项 +1 时，优秀 +1.2。
- 精确成长公式没公开（缺口截图 #2 用来反推）→ 默认 ⚙：`每级第 i 项成长 = 资质_i × 成长系数 × (1 + 悟性×1%) / 3500`，成长系数：普通 1.0、优秀 1.2、杰出 1.8、卓越 2.6、完美 3.4~4.0（随机）、超凡 4.0 + 0.05×幻化度。粗校验：资质 9000、完美 3.8、悟性 20 的宠物 160 级时该项约 1900，和玩家资料里 160 级成品宠主属性“约 2000”同一量级【D-惊舟】。
- 宠物一级 → 二级属性换算：没公开，默认沿用人物换算表（§1.2）⚙。
- **资质丹（宠物仙丹）**：常用灵、玄、神三档；一套 5 颗、一包 5 套；“自动放入”后升 1 级消耗对应槽 1 颗，**临时**提高该项资质，让这一级长得更多【D-曦月；官指·养成攻略】。加成值没公开 → 默认 灵 +5%、玄 +10%、神 +15% 资质 ⚙。
- **还童**【已证实｜道具介绍】：还童丹（非神兽）/ 神兽还童丹 → 回到 1 级、未绑定，资质、成长率、是否变异重新生成，悟性和领悟技能归零。资质重生丹只重随资质。灵异金丹可让宠物 100% 变异【青元攻略网，玩家资料】。
- **爆资**：资质超过种族上限（变异 +10% 造成）叫“爆”，两项叫“双爆”；成品宠一般 1~2 项爆、其余满【D-曦月】。

### 6.4 培养【已证实｜官指·宠物培养系统 28356】
- 宠物面板「培养」：每次随机重算 5 项“附加属性”，显示新旧对比（绿箭头升、红箭头降），点「保存」才生效，「取消」保留原值。
- **普通培养**（银票）上限低，**高级培养**（金票）上限高；玩家经验：银票能到金票上限的约 1/3【D-曦月】。
- 上限受资质、成长率、悟性、等级影响；某项满了显示“满”，继续培养该项**可能下降**；最小 +0。升级不丢；**还童会清掉**。
- 上限和费用没公开（缺口截图 #9）。默认 ⚙：`单项上限(高级) = 资质 × 成长系数 × 等级 / 20000`；普通培养上限 = 高级 × 1/3；每次在 [当前−8%上限, 当前+12%上限] 内随机；普通 2 两银票/次，高级 5 两金票/次。

### 6.5 宠物技能
**分类**【已证实｜官指·宠物技能 6988、6652】：
- **天赋技能**：捕捉或使用万化药品时随机生成；**随宠物等级自动升级**；威力大、消耗高。
  - 重洗：**万化灵丹（神兽用）/ 万化秘露（非神兽用）**，整组重随，有概率出新天赋。
  - 学单个：**天赋精华**（技能栏满了会覆盖别的技能）。
  - 每种宠物的每个天赋有稀有度：**B 常见、A 罕见、S 稀有**；同时拿多个 S/A 很难。
- **非天赋技能**：
  - **书学**：商城宠物技能书。第 k 级需要修为 `200 × (k−1)`（1 级 0、2 级 200、3 级 400…）。学书时**可能遗忘另一个非天赋技能**，已有技能越多遗忘率越高，界面上会显示遗忘率；显示 100% 时必定遗忘一个。
  - **升级领悟**：修为满足下一级需求时，每次升级概率领悟/升级；已有多个天赋时概率很低。
  - **领悟功能**（查看详情→领悟技能）：消耗 1 个智慧守护者之泪（帮会大厅每天领 1 个）+ 混元延寿露 + 个人帮会声望；必须是**绑定**宠物且有**空技能栏**；悟性越高成功率越高；可能领悟到已有技能；少于 3 个技能的宠物效果最好。【官指·技能领悟 14512】
- **等级**：书学技能学到 **10 级**；10 级后用特殊道具“修炼”到 **11 级**（概率成功）。修炼道具“××之尘”：在迷途沙洲等地用 30 个“白银英雄令”挑战罗洋、罗雪、钱海、韦季、李斤斗、古楠长者，各给一种鼓励包（烈风/混乱/力量/魔力/北冥/智慧/灾祸/龙息/魔铁/大地/龙魄/黑暗/火焰/法力/法术/生命/战术/幽冥/元素/自然/天空/治愈之尘等）。白银英雄令：迷途沙洲打/抓“羊多多”交给羊多利。【官指·宠物技能】玩家资料里有“20 法烧”“技能等级 10 级以上要道具+当前修为”→ 现版本上限推测 **20 级**【D-惊舟、D-曦月】⚙。
- **技能栏**：灵异秘卷 6~10 逐格开到 **10 格**；觉醒 +1（11 格）；飞升 +1 飞升专属栏（第 12 个）【D-曦月、官指·觉醒/飞升】。初始格数没公开 → 默认 5 格 ⚙。
- **具体数值**（含遗忘率，缺口截图 #7）：只公开了“厚皮”1 级 +10 耐力、每级再 +6（2 级 16、3 级 22…）。其余数值没公开 → 默认被动技能 `+ (4+6×Lv)` 对应属性或 `+(3+1.5×Lv)%`，主动技能 `(0.9+0.05Lv)×(主攻+40Lv)` ⚙。
- 常用天赋清单（名称原版）：见 `systems_data.json › pets.talents`（含效果描述，来自宠物大全）。

### 6.6 炼化（万兽密录 / 万兽宝鉴）【已证实｜官指·可炼化的技能 27899、炼化技能的升级 27897】
- 道具：**万兽密录（增强、防护）**、**万兽宝鉴（增强、防护）**。
- **普通炼化**：对拥有可炼化技能的宠物（宠物岛炼化专用宠，如迅猛狼、厚皮熊、神力虎、蜘蛛、蜈蚣的“野性赐福”，灵动羊、斑斓蛇的“战斗韧性”）用空白万兽密录 → 得到录有 **丹药健体** 的密录 → 给目标宠物学。
- **组合炼化**：用“录有丹药健体的密录”去抽另一个技能 → 变成新的密录：

| 智慧超群 | 水灵润心 |
| 金丝软甲 / 硬甲壳 / 招架 / 火焰甲 / 仙侣宝衣 | 铁骨铮铮 |
