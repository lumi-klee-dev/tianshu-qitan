# 天书奇谈 · 网页版玩法复刻原型（tianshu-qitan）

一个用纯 HTML/CSS/JavaScript 写的浏览器原型，用原创代码和占位美术，复刻网游《天书奇谈》公开的玩法规则：装备与打造、宠物、技能心法、徽章元神、称号法宝、骑宠兽魂、精灵、结义帮会、转生、经脉、地灵等系统。

## 怎么运行
- 直接双击打开 `index.html` 就能玩，不需要构建。
- 或者起一个本地服务：`python3 -m http.server 8765`，然后访问 http://127.0.0.1:8765/
- `?reset=1` 清空存档恢复演示角色；更多 URL 参数见 `CHANGELOG-v1.4.md`。
- 存档保存在浏览器 localStorage（`tsq_save_v2`）。

## 目录
- `index.html`、`css/`、`js/`、`data/`：游戏本体
- `CHANGELOG-v1.3.md`、`CHANGELOG-v1.4.md`：近两版更新日志
- `docs/`：整理的系统规格文档（`全系统规格.md`、`装备与打造系统规格.md` 等）
- `test_r11.js`、`harness_r11.js`、`verify_browser.js`：自测脚本
